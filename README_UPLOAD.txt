UPLOAD LOCATION
Replace the root-level index.html in your GitHub repository:
84kgvfhwbp-sys/jess-life-ceo-planner

Do not place this file inside /v2/ if you are currently using:
https://84kgvfhwbp-sys.github.io/jess-life-ceo-planner/

BEFORE UPLOADING
1. Open the current planner.
2. Use Backup data in the lower-left menu.
3. Download a JSON backup.

GITHUB STEPS
1. Open the repository on GitHub.
2. Select the existing root-level index.html.
3. Choose Edit or Delete/Upload as needed.
4. Replace it with the index.html in this folder.
5. Commit the change.
6. Wait about one minute, then open the planner.
7. Use Command + Shift + R once to clear the older cached page.

NEW IN THIS UPDATE
- Dedicated Top Priority form.
- Priority levels: Low, Medium, High and Critical.
- Task statuses: Pending, Active, Paused and Completed.
- Checking a task automatically changes its status to Completed.
- Reopening a task restores its earlier status or sets it to Active.
- One shared task model across Home, Plan and Work.
- Required task date and optional task time.
- Tasks with no time display as Start of day.
- Task details, category, related client/person/project, assignee, estimated minutes and tags.
- Task and priority attachments.
- Detailed Notes & Follow-ups records.
- Related client/person/project, contact details, follow-up date/time, next action and full note.
- Notes category library.
- Optional linked task creation from a note or follow-up.
- Up to three stored photos/files per task or note.
- Click any task or note to open the complete record and edit it.

ATTACHMENT LIMITS
This is a browser-based planner. Photos are resized before storage. Other files must be under 350 KB each, with no more than three attachments per record. Always keep backups because browser storage is limited.
