LIFE & CEO OS — STABLE GITHUB UPLOAD

This package contains a standalone, single-file planner.
It does NOT use compressed chunks, external libraries, injected overlays, or a separate build process.

RECOMMENDED SAFE UPLOAD

1. Open your GitHub repository:
   84kgvfhwbp-sys/jess-life-ceo-planner

2. Before replacing anything, download a copy of the repository or rename your current file/folder as a backup.

3. To use this as the V2 staging version:
   - Open the existing v2 folder in GitHub.
   - Delete or rename the current v2/index.html.
   - Upload the index.html from this package directly into the v2 folder.
   - The chunks and overrides folders can remain, but the new index.html does not use them.

4. Commit the change.

5. Open:
   https://84kgvfhwbp-sys.github.io/jess-life-ceo-planner/v2/

6. Hard refresh once:
   Mac: Command + Shift + R

DATA

- Data is saved in the browser using localStorage.
- Storage key: life-ceo-os-stable-v1
- The planner attempts a one-time compatible import from:
  jess-life-ceo-planner-v1
- The original storage is not deleted.
- Use “Backup data” at the bottom of the left menu to download a JSON backup.

MENU STRUCTURE

- Left: permanent main menu.
- The menu can be condensed to icons and expands on hover.
- Right: page-specific Action Menu.
- Clicking an action icon opens a working drawer from the right.

FILES REQUIRED

Only index.html is required for GitHub Pages.
